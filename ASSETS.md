# Asset provenance

Every non-code asset shipped with OpenDrape, where it came from, and its license.
Add a row before committing any new asset.

| Asset | Source | License |
|---|---|---|
| `assets/icon@2x.png`, `assets/icon.ico` | Generated by `cargo xtask icons` (this repository) | GPL-3.0-or-later |
| `crates/render/src/studio/environment_data.rs` (studio lighting: 9 SH coefficients and a key light) | Baked by `cargo xtask studio` from Poly Haven "Studio Small 08" by Sergej Majboroda, 1k HDR (https://polyhaven.com/a/studio_small_08), fetched and MD5-checked by `scripts/fetch-studio-hdri.sh`; the HDRI itself is not shipped | CC0 1.0 (https://polyhaven.com/license) |
| egui default UI fonts (embedded via `epaint_default_fonts`) | egui project | OFL-1.1, Ubuntu Font License 1.0 |
| Phosphor icon font, regular weight (embedded via `egui-phosphor` 0.14.0) | Phosphor Icons, https://github.com/phosphor-icons/core | MIT |
| All Rust dependencies | crates.io | Listed with full texts in `THIRD_PARTY_LICENSES.html`, generated by `cargo about` and shipped in every download |
| `assets/forms/women-torso.form.json`, `assets/forms/men-torso.form.json` | Made in-house: built by `scripts/forms/loft_base.py` in Blender 5.2 LTS and exported by `scripts/forms/export_form.py` (`sh scripts/forms/blender.sh loft <id>`, then `export <id>`), with hand-written `assets-src/forms/<id>.meta.json` | CC0 1.0 |
| `assets/forms/charts/*.json` | OpenDrape's own size charts (graded in-house). No table is copied | CC0 1.0 |
